# 🛠️ Installation and Pre-requisites

Welcome to the **OpenCV Learnings** repository! This folder contains all the necessary instructions and environment setup guides required before running and writing OpenCV code on your local machine.

---

## 📋 Pre-requisites (Pehle kya hona chahiye?)

Before installing OpenCV, make sure your system has the following tools installed:

1. **Python (v3.x or higher)**
   - OpenCV requires Python to run scripts.
   - Verify installation by running this in your terminal/command prompt:
     ```bash
     python --version
     ```

2. **Pip (Python Package Manager)**
   - Pip comes pre-installed with modern Python versions and is used to install libraries.
   - Verify installation:
     ```bash
     pip --version
     ```

3. **Git (Optional but Recommended)**
   - Required for cloning the repository and pushing your changes to GitHub.
   - Verify installation:
     ```bash
     git --version
     ```
